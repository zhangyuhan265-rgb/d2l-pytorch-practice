## 核心 6 个知识点

- [ ] 1. 旋转矩阵 SO(3) —— 怎么用 3×3 矩阵表示「朝向」
- [ ] 2. 齐次变换 SE(3) —— 把「旋转 + 平移」打包成 4×4 矩阵
- [ ] 3. 指数积 PoE 公式 —— 用矩阵指数表示正运动学
- [ ] 4. 雅可比 J(q) —— 关节速度 ↔ 末端速度的偏导数矩阵
- [ ] 5. 逆运动学 —— 从末端位置反解关节角
- [ ] 6. 奇异位形 —— det(J) = 0 时机器人为什么「卡住」
