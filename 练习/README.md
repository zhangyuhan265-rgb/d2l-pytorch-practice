# 练习目录

按教材章节组织。教材在 `../_教材/pytorch/`。

## 怎么用

全部在 VS Code 里完成：

| 干什么 | 去哪 |
|---|---|
| 读讲解、看图 | `../_教材/pytorch/<章节>/xxx.ipynb` |
| 跑教材示例 | 同一个 notebook，`Shift+Enter` |
| **写自己的练习** | **本目录对应的章节文件夹** |

## 文件命名约定

| 前缀 | 含义 |
|---|---|
| `NN_xxx.py` | 正式练习（NN 是节号，如 `01_` 对应 2.1 节） |
| `深入_xxx.py` | 某个知识点的加深演示（通常是回答疑问时生成的） |
| `验证_xxx.py` | 验证某个规则/结论的小脚本 |
| `谜题_xxx.py` | 带思考题的小实验 |

## 每个练习文件的跑法

文件用 `#%%` 分成多个单元格：

- 光标放在某格里 → `Shift + Enter` 只跑这一格
- 格子上方会出现 `Run Cell` 小字，点它也行
- **第 0 格必须先跑**（里面有 import），否则后面会 NameError

## 实用补充

### notebook 里的讲解是什么格式

教材的每个 `index.ipynb` 或 `xxx.ipynb` 里，内容分两类格子：

- **Markdown 格子** —— 讲解文字、公式、图片。**只读，不用跑。**
- **代码格子** —— 左边有 `[ ]` 或 `[n]`，可以按 `Shift+Enter` 运行。

看到 `:label:` 或 `:numref:` 这种文字，是 d2l 的 Sphinx 交叉引用标记，
VS Code 不认，**原样显示是正常的，忽略即可。**

### d2l 教材的两个小坑

**① 导入方式反直觉**

```python
from d2l import torch as d2l      # ← 教材都这么写
```

**不是 `import d2l`**。因为 d2l 库按框架分模块（`d2l.torch` / `d2l.mxnet`），
这行把 `d2l` 这个名字指向了 torch 子模块。

**② 有些格子会下载数据**

第一次跑某些格子会下载数据集（MNIST 约 11 MB、CIFAR 约 170 MB），
**要等一会儿，不是卡住了。**

### 关掉内核注意

`.py` 交互窗口和 notebook 各自维护自己的"内存"。

- **关掉交互窗口 / 重启内核** → 变量全部清空
- 重新跑时必须**从第 0 格开始按顺序**

**判断是否遇到这个问题**：报 `NameError: name 'xxx' is not defined`，
而那个变量明明在上一个格子里定义过。
